Privacy Policy

Last updated: November 17, 2026

YouTube API Test is a personal tool used only by its owner, on the owner's own YouTube channel. It uses YouTube API Services; use is subject to the YouTube Terms of Service and Google's handling of data is described in the Google Privacy Policy.

What it accesses

  • The owner's channel video list, video metadata and YouTube Analytics reports.
  • Permission to upload videos to that channel.

Use and storage

Data is stored only on the owner's computer and used only to plan uploads. Nothing is sold, shared or used for advertising. No data about other people is collected.

Revoking access

Access can be removed any time at Google account permissions; local data is deleted when no longer needed.
